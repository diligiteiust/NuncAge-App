# Starter dashboard

These are example items so Nunc Age is not empty the first time you open it. Edit them, tick them, or delete the whole Starter list once your own lists are in place.

Tick a box in the menu or on this dashboard when you finish something. The app records the tick and notifies the agent that owns the item, when that agent has a notify URL.

## How the lists are grouped

- **Today** — things that should happen today
- **Work** and **Personal** — ordinary open work
- **Home** — household tasks
- **Waiting** — blocked on someone else, so they stay off the top of the menu unless you give them a due date
